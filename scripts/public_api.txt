# The public interface of the chunk library, frozen for 1.0 (CHANGELOG.md,
# versioning policy; docs/api.md says how to use each name).
#
# scripts/check_public_api.py checks it against the tree (ctest check_public_api):
#   - the [header] sections are exactly the headers of chunk/public/chunk/
#     outside internal/: a header added, moved or removed fails until this
#     file says so;
#   - every name of a section must still be reachable from its header -- a
#     word of the header or of a chunk/ or fast_allocators/ header it
#     includes, directly or not: a public name removed or renamed fails.
# A change to this file is an interface change: record it in CHANGELOG.md
# (before 1.0 a MINOR release, after it a MAJOR one, or a deprecated alias).
#
# Members of the public classes that name the library's machinery are NOT part
# of the interface, though a program can spell them: they can change in any
# release. They are listed in [not public] so that nobody adds them above.
